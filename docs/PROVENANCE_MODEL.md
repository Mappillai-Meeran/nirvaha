# DATA PROVENANCE MODEL — NIRVAHA PHASE 12

## Source Classification vs. Verification Status

Nirvaha strictly separates **Data Source Classification** from **Verification Status**.

### Source Classification (`DataClassification`)
- `OFFICIAL`: Government-published data source (e.g. LAD maps, IMD weather, PWD charter).
- `CITIZEN`: Citizen-submitted incident reports and geotagged evidence.
- `DERIVED`: Analytical model calculations generated by Nirvaha (e.g. Risk score, Priority score).
- `SIMULATED`: Synthetic stress-test records.

### Geometry Status (`GeometryStatus`)
- `OFFICIAL`: Raw machine-readable vector GeoJSON directly published by government GIS portal.
- `DERIVED_FROM_OFFICIAL`: Geometry extracted/digitized from official government PDF gazette notifications or maps.
- `APPROXIMATE`: Estimated boundary geometry.
- `UNVERIFIED`: Polygon boundary awaiting review.

### SLA Status (`SlaStatus`)
- `WITHIN_STANDARD`: Operation is within published Citizen's Charter target days.
- `APPROACHING_DEADLINE`: Within 3 days of target deadline.
- `OVERDUE`: Target deadline exceeded.
- `COMPLETED`: Incident resolved.
- `NOT_APPLICABLE`: No published policy rule applies to incident category.
